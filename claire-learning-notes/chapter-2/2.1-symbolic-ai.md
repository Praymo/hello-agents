# 规则写得再全，也装不下现实：从符号主义理解早期智能体

> Claire 的个人学习笔记｜基于 Datawhale [Hello-Agents](https://github.com/datawhalechina/hello-agents) 第 2 章 2.1 节整理。文中的类比与现代 Agent 连接是我的学习理解，不代表原教程作者观点。

> **这一节最让我意外的地方：最早的 Agent 根本不会“学习”。** 它的聪明来自人类事先写好的符号、知识和规则。

## 从一个问题开始：智能能不能被“写出来”？

今天我们习惯把人工智能和神经网络、训练数据、大模型绑定在一起。但早期 AI 研究者走的是另一条路：如果人的推理可以拆成明确的概念和规则，那么是不是只要把这些规则写进计算机，智能就会从中出现？

这就是**符号主义（Symbolic AI）**的核心直觉。

在这个框架里，世界先被翻译成符号，符号之间再通过规则发生关系。机器并不是从大量样本里“学会”下一步怎么做，而是在一个已经搭好的逻辑世界里，根据输入事实不断匹配规则、推出新事实，最后得到结论或行动。

我更愿意把它想成一个**预先设计好的机关箱**。你往里面丢进一个事实，它不会自己发明新的规律，而是沿着设计者铺好的轨道一路触发机关。只要轨道覆盖到了，过程就非常清楚；轨道没铺到，机器就会突然变得很笨。

## PSSH：把“心智”变成工程问题

1976 年，Allen Newell 和 Herbert A. Simon 提出了**物理符号系统假说（Physical Symbol System Hypothesis, PSSH）**。它最重要的意义，在我看来不是“证明了机器一定可以像人一样思考”，而是做了一次非常大胆的降维：

> 与其把智能当成一个模糊的哲学谜题，不如先假设它可以被表示、被操作、被计算。

这个假说包含两个方向：如果一个系统能够对符号进行表示和操作，那么它可能足以产生智能行为；反过来，任何通用智能背后，也必须存在某种符号处理能力。

这给早期 AI 一个极强的工程信心：**智能也许不是玄学，它可能是一套可以实现的计算结构。**

## 专家系统：把人的经验压成 IF–THEN

符号主义最经典的产品之一就是**专家系统**。

它可以粗略拆成两块：

- **知识库**：存放专家经验，比如 IF 发烧 AND 咳嗽 THEN 考虑呼吸道感染；
- **推理引擎**：负责决定现在应该匹配哪些规则，以及怎样从已知事实推出新的结论。

这里有两种很有意思的思考方向：**前向推理**从现有事实一路往后推，像“我现在知道 A 和 B，所以还能推出什么”；**后向推理**则先假设一个目标，再反过来追问“要证明它，我还缺什么证据”。

这让我第一次意识到：所谓“推理”，并不一定天然等于大模型输出一串自然语言。它完全可以被实现成一个规则搜索过程。

教材里提到的 MYCIN 就是这种思路的代表。它用大约 600 条 IF–THEN 规则辅助血液感染诊断，并主要采用后向推理来逐步寻找证据。它厉害的地方恰恰说明：**在边界明确的领域，只要知识整理得足够好，规则系统真的可以表现得非常聪明。**

## SHRDLU：为什么“积木世界”如此重要？

另一个让我很喜欢的例子是 SHRDLU。它生活在一个由积木组成的虚拟世界里，可以理解自然语言命令、记住环境状态、规划动作，甚至解释自己为什么做了某件事。

这已经非常像今天 Agent 的“感知 → 思考 → 行动”闭环了。

但关键问题也藏在这里：**SHRDLU 的世界太干净了。** 里面的物体、关系和规则几乎都可以被完整描述。真实世界却不是一盒乐高，它充满模糊、例外、上下文和默认常识。

## 符号主义真正撞上的墙

于是问题出现了。

第一堵墙是**知识获取瓶颈**。如果智能完全依赖显式知识，那就意味着人类必须把世界一点一点写进去。但人真正知道的很多东西，自己都很难说清楚，更别说全部整理成规则。

第二堵墙是**脆弱性**。规则系统在熟悉区域里非常稳定，但只要出现设计者没有预见的新情况，它可能不是“稍微差一点”，而是直接掉出轨道。

第三堵墙更有趣：现实世界一直在变化。系统执行一个动作以后，哪些东西发生了变化，哪些没有？人类几乎下意识就知道，但符号系统需要明确表示这些状态，这会迅速把规则数量推向失控。

所以问题不是“规则毫无用处”，而是：**开放世界太大，不可能完全靠人工把智能写完。**

## 我现在看现代 Agent，会多看一层

学完这一节以后，我反而不觉得符号主义已经被 LLM 淘汰了。

现代 Agent 里面依然到处都是符号主义留下的影子：工具的参数 Schema、工作流条件、权限规则、状态机、验证器、结构化输出、业务约束，这些都不是模型“自由发挥”的地方，而是明确规则在发挥作用。

真正发生变化的更像是分工：

**以前：人类试图把知识和规则全部写给机器。**

**现在：模型从数据中学习大量隐式知识，人类只把那些必须确定、必须可控的边界显式写出来。**

这可能也是我现在理解 Agent 系统时最有用的一条线索：

> 设计一个 Agent 时，不只是问“模型够不够聪明”，还要问：**哪些事情应该交给模型判断，哪些事情应该被规则牢牢钉住？**

我觉得这比单纯讨论“符号主义 vs. 大模型谁更先进”有意思得多。现代 Agent 更像是两种思想的重新拼装：让模型处理模糊世界，让规则负责确定边界。
